Def. of Garbage Collector:
----------------------------------------
=>Garbage Collector is one of the In-Built Python Program in Python Software and It is running Behind of Regular Python Program and whose Role is Collects Un-Used Memory space and Improves the 
Performance of Python Based Applications.
=>Hence Garbage Collector takes take about Automatic Memory Management.
